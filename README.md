# XelzSpace

A minimalist, dark-futuristic personal portfolio and blog for XelzSpace.

## Features

- Indonesian / English language toggle
- Dark / light theme with saved preference
- Searchable blog articles
- Projects and about sections
- Responsive navigation and layouts
- Lightweight reveal animations
- Contact form UI

## Run locally

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
